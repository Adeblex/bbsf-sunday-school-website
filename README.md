# BBSF Sunday School Family Website

A multi-page, responsive website built for the Sunday School Family — a teaching
unit of the Bowen University Baptist Student Fellowship (BBSF). Built as a final
project for a Web Design course.

🔗 **Live site:** https://adeblex.github.io/bbsf-sunday-school-website
📁 **Repository:** https://github.com/Adeblex/bbsf-sunday-school-website

## About

The Sunday School Family is one of the four teaching units of the BBSF at Bowen
University. This site serves as its digital home — introducing the unit, its
leadership, its families, and its activities to the wider campus community.

## Pages

- **Home** — Introduction, vision, mission, and recent updates
- **Executives** — Current and past unit leadership
- **Families** — The unit's family groups
- **Events** — Past and upcoming activities, with photos
- **Archives** — Past session themes, past executives, and downloadable outlines
- **Contact** — Contact form and unit information

## Built With

- HTML5
- CSS3 (custom properties, Flexbox, Grid, responsive media queries)
- Vanilla JavaScript (form validation, mobile navigation, scroll-based nav styling)

## Features

- Fully responsive layout across mobile, tablet, and desktop
- Client-side contact form validation
- Mobile hamburger navigation menu
- Scroll-triggered glassmorphism effect on the navigation bar
- Executive slideshow by session/year
